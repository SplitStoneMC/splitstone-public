# Changelog

Changes to the public API, newest first.

## Version 1 (not yet live)

- The first version of the API at `https://api.splitstonemc.com/v1/`: players, their matches, seasons and head-to-heads, matches with splits, timelines and Twitch VOD moments, live matches, Elo ladders, time records, the playoff race, weekly cups and the service's status.
- Player keys, made in the game's settings, read the player's own match or private room for stream overlays.
- Developer keys raise the request limit; ask contact@splitstonemc.com.
